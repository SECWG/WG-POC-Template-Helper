## 功能展示

> 非最新功能效果

### 模板管理

查看模板详情和 YAML 内容，提供新建、编辑、重命名和删除模板文件等能力。

<img width="1438" height="851" alt="image" src="https://github.com/user-attachments/assets/c3468146-bfa4-41a5-8b61-0fc6fd54d67d" />

配置本地 Nuclei 可执行文件，对指定目标和模板范围发起扫描。

## 更新历史

### v2.0.0 (2026-09-01)

1. 【全新】重新设计桌面工作台界面，统一模板管理、扫描任务、模板项目和程序配置的布局、配色与操作反馈
2. 【新增】项目快速切换入口，可在侧边栏直接查看并切换当前模板项目，多个模板库之间切换更加便捷
3. 【优化】模板项目管理，集中展示项目目录、模板数量、索引状态和最近更新时间，并简化新增、保存、切换和删除流程
4. 【新增】完整的目录管理能力，支持在目录树中前往目录、新建目录、重命名目录、删除目录和直接新建模板
5. 【新增】模板批量操作，可将所选模板加入扫描、移动到其他目录或批量删除；移动时遇到同名文件会自动跳过
6. 【优化】目录选择体验，新建、编辑、导入和移动模板时均可展开、收起和搜索目录，并默认定位到当前选中目录
7. 【优化】模板查看与编辑体验，详情页聚焦模板原始内容，编辑器支持自动换行、查找替换、格式化和更清晰的内容选择效果
8. 【优化】模板校验流程，在新建、保存、导入和建立索引前检查模板完整性，及时提示无法被 Nuclei 正常使用的模板
9. 【优化】索引管理流程，区分“建立索引”和“重建索引”，重建前提供确认说明，并集中展示跳过、失败和重复模板等结果
10. 【升级】扫描配置能力，支持按当前项目、目录、所选模板或自定义路径设置扫描范围，并提供等级、标签和模板 ID 筛选
11. 【新增】扫描运行预设和附加参数，可根据不同任务调整速度、并发、超时、代理及其他 Nuclei 运行选项
12. 【优化】扫描任务展示，统一任务状态、目标数、模板数、命中数和时间信息，长文本与多任务场景下更易浏览
13. 【新增】请求与响应查看，启用保存请求响应后，可在任务原始数据中按类型浏览并查看对应文件内容
14. 【优化】扫描任务生命周期，完善运行状态跟踪、取消、重新运行、删除、命中详情、运行日志和原始数据查看
15. 【升级】程序配置页面，统一管理 Nuclei 运行环境、产品授权、版本检查和程序信息，并支持手动刷新相关状态
16. 【升级】产品授权体验，不再通过启动弹窗阻断基础功能，可在程序配置中完成激活、刷新、移除授权和访问授权中心
17. 【优化】完善 Windows 与 macOS 使用体验，改进项目切换、路径选择和本地数据保存，并提供 Intel 与 Apple Silicon 对应构建
18. 【修复】修复快速切换项目后可能显示上一项目模板，或后续查看、编辑和操作引用错误项目的问题

### v1.0.0 (2026-06-27)

✨ 首次发布：

1. 【新增】模板项目管理，支持配置和切换多个本地 Nuclei 模板目录
2. 【新增】模板索引与目录树，可按本地目录结构浏览模板并查看索引结果
3. 【新增】模板检索，支持按关键字、字段、严重等级、目录和分页筛选模板
4. 【新增】模板查看与维护，支持新建、查看、编辑、重命名、删除和基础内容校验
5. 【新增】模板导入，支持选择文件、选择目录和拖入模板，同名文件自动跳过
6. 【新增】本地 Nuclei 扫描，可配置目标、模板范围、筛选条件和常用运行参数
7. 【新增】扫描任务记录，支持查看任务概览、命中结果、运行日志和原始数据
8. 【新增】授权配置，可查看设备信息、填写授权码并了解本地授权状态
9. 【新增】程序信息与版本检查入口，便于查看当前版本和获取后续更新
